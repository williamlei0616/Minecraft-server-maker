# Minecraft Server Maker

Pick your options (version, RAM, GUI, difficulty, command blocks, ...), tick the Minecraft
EULA, download a small zip, unzip it and double-click one file. The start script downloads
the official server jar from Mojang on your machine, verifies it, and starts the server with
your settings already applied.

This site never stores or serves Mojang's server jar, and never writes `eula=true` unless
you tick the EULA box. Not affiliated with Mojang or Microsoft.

## Requirements

- Node.js 20 or newer
- Java 21 or newer, only for `npm run profiles` and `npm run e2e`

## Commands

```bash
npm install
npm run typecheck && npm run lint && npm test
npm run dev        # Next.js dev server
npm run build      # static export to out/ (set PAGES_BASE=/repo-name for a Pages subpath)
npm run versions   # refresh public/versions.json from Mojang
npm run profiles   # record what each version's real server generates (needs Java)
npm run bundle -- 26.3 --user Notch --set max-tick-time=120000 --map "My World"   # build a bundle without the UI, into .out/
npm run e2e        # build a bundle and run its start script for real (needs Java 21+, internet)
```

## Structure

The UI is a Next.js app with `output: 'export'` (static files only, no server).

- `src/app/`: the thin Next shell (routes, fonts, global styles)
- `src/ui/`: the page itself; talks to the core library only through `@/core`
- `src/core/`: bundle, start scripts, config and `server.properties` logic
- `src/i18n/`: all user-facing text; English at `/`, Traditional Chinese at `/zh-hant/`
  (a test fails if a language misses a string)
- `scripts/`: the CI jobs that generate `public/versions.json` and `public/profiles/`
- `tools/`: the command-line bundle builder and the end-to-end check

## Testing

`npm test` also runs the real start scripts (`start.bat` through cmd, `start.sh` through sh)
against a local stand-in for Mojang's name lookup and a fake `java` (`tests/scripts`, about 40
seconds on Windows). A part skips itself when its shell is missing.

A second dev server can run next to the first (Next locks its build folder):
`NEXT_DIST_DIR=.next-alt npx next dev -p 3100`.

## Data

`public/versions.json` and `public/profiles/` are generated by the "Update versions and
profiles" workflow, which refreshes them from Mojang every six hours and commits them only
when every listed version has a current profile.
